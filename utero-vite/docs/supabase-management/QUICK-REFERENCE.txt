  401 Unauthorized:
    • Check API keys match (local .env vs server volumes/functions/.env)
    • Verify x-api-key header is sent
    • Check function .env file exists

  500 Server Error:
    • Check edge-functions logs: docker-compose logs edge-functions
    • Verify BLOG_API_KEY is set on server
    • Check function code for errors

  404 Not Found:
    • Verify function deployed: ls volumes/functions/blog-auto-post/
    • Re-deploy: .\deploy-function.ps1
    • Check service is running: docker-compose ps

  Function Not Loading:
    • Restart service: docker-compose restart edge-functions
    • Check logs for startup errors
    • Verify file permissions

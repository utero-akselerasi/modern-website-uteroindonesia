┌─────────────────────────────────────────────────────────────────────────────┐
│ ⚠️  COMMON ISSUES                                                          │
└─────────────────────────────────────────────────────────────────────────────┘

  Problem: App won't start
  → Check Node.js version (18+ required)
  → Verify server.js exists in root
  → Check logs: cPanel → Node.js App → Open logs

  Problem: 404 on all pages
  → Ensure .next/ folder uploaded completely
  → Check Application URL matches domain

  Problem: Images not loading
  → Verify public/ folder uploaded
  → Check file permissions: chmod -R 755

  Problem: Port already in use
  → Let cPanel auto-assign port (it's normal)
  → Don't hardcode port in server.js
